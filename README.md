## Open-source localization

<sub>오픈소스 한국어 현지화</sub>

I contribute Korean localization to Android and mobile open-source projects, reviewing real UI context, terminology consistency, Android resource structure, and usability rather than only replacing strings.

<sub>Android와 모바일 오픈소스 프로젝트의 한국어 현지화에 기여합니다. 단순 문자열 치환보다 실제 UI 문맥, 용어 일관성, Android 리소스 구조와 사용성을 함께 확인합니다.</sub>
